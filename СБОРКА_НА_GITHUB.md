# Carnage Music Finder — сборка APK на GitHub

## 1. Загрузка проекта

1. Создайте пустой репозиторий на https://github.com/new (например, `CarnageMusicFinder`).
2. Распакуйте `CarnageMusicFinder-GitHub.zip`.
3. Через **Add file → Upload files** загрузите **все папки и файлы изнутри** `CarnageMusicFinder` в корень репозитория (папка `.github` должна попасть в корень).
4. Нажмите **Commit changes**.

В ZIP уже находится `.github/workflows/android.yml` — автоматическая сборка на GitHub Actions.

## 2. Получение APK

1. Зайдите в репозитории в раздел **Actions**.
2. Выберите **Build Android APK**.
3. Если сборка не запустилась после загрузки, нажмите **Run workflow → Run workflow**.
4. После успешной сборки откройте её страницу и скачайте артефакт **CarnageMusicFinder-APK**.
5. Распакуйте скачанный артефакт: внутри будет `app-debug.apk` — Android APK для установки.

**Важно:** из этой среды собрать или протестировать APK не получилось: отсутствуют Android SDK и Gradle и нет доступа к загрузке зависимостей. Успешное прохождение Actions не гарантировано, но CI настроен для проверки компиляции и тестов. Если сборка покажет ошибку, сохраните текст логов Actions для исправления.

## 3. Работа с приложением

1. Вставьте ссылку на плейлист Яндекс Музыки, нажмите **+ Плейлист**.
2. Добавьте другие плейлисты; каждый хранится отдельно.
3. Выберите **Найти во всех**, чтобы выполнить поиск для всех импортированных треков.
4. Для спорных совпадений нажмите на трек и вручную укажите корректную запись.
5. Для загрузки файлов, на получение которых вы имеете право, подтвердите соответствующий пункт и используйте **Найти + скачать** или **Скачать выбранные**.
6. MP3 сохраняются в общей папке Android **Музыка/Carnage/Имя плейлиста**.
7. Кнопка **Экспорт отчёта CSV** создаёт список треков с результатами, в том числе ошибками и не найденными записями.

### Об импорте из Яндекс Музыки

Приложение использует неофициальный API Яндекса. Некоторые ссылки доступны только с OAuth-токеном аккаунта. Вставленный токен используется только для импорта, в памяти приложения, и не сохраняется в библиотеке и файлах. Никогда не загружайте токен в репозиторий и не пересылайте посторонним.

Поддерживаются ссылки вида `https://music.yandex.ru/users/login/playlists/123` и `https://music.yandex.ru/playlists/123456:789`. Для новых коротких ссылок приложение пытается восстановить полные параметры; если это не получится, импортируйте CSV/M3U со строками `Исполнитель - Название`.

### Что проект НЕ обещает

- Не гарантирует, что найдёт каждый трек: поставщик, права и региональные ограничения могут мешать поиску/скачиванию.
- Не анализирует нецензурные слова на звуковой дорожке. Поиск Explicit/Uncensored — по заголовкам и метаданным, точность ограничена.
- Не взламывает Яндекс Музыку, не скачивает DRM-защищённые файлы.
- Версия 0.1.0 требует открытого приложения во время поиска/скачивания; сохранённые очереди можно продолжить после повторного открытия.
